# Referenzen

Verwandte Open-Source-Projekte als Anregung für Struktur und Oberfläche. Es gibt nach bisherigem Wissensstand keinen fertigen Open-Source-Klon von Port Royale.

## OpenPatrician

Freie Java-Implementierung von Ascarons *The Patrician* und *The Patrician 2* (Hanse im Mittelalter). Gleiche Spielfamilie wie Port Royale, daher nahe am Wirtschaftsmodell dieses Projekts. Aufbau mit Wirtschaft, Städten, Schiffen, Taverne und Werft. Das Projekt scheint seit längerem ruhend zu sein (die jüngsten gefundenen Neuigkeiten stammen von 2013), den aktuellen Stand und die Lizenz auf SourceForge prüfen, bevor Code übernommen wird. Als Architekturvorlage nutzbar, ohne Code zu kopieren.

- Projektseite: https://openpatrician.sourceforge.io/

## Hanse2.0

Hobbyprojekt, inspiriert von Patrizier IV und Anno 1404. Datengetrieben (Städte aus einer JSON-Datei), Entity Component System, Handelsfenster mit Schieberegler auf logarithmischer Skala für Kaufmengen. Gute Anregung für die Handelsoberfläche.

- Projektseite: https://flavortown.hackclub.com/projects/16154

## Hinweis

Von diesen Projekten werden Ideen übernommen, nicht Code oder Material. Vor jeder Code-Übernahme die Lizenz prüfen.
